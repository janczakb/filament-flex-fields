## Gravity UI Icons

This package uses icons from [Gravity UI Icons](https://github.com/gravity-ui/icons) (`@gravity-ui/icons`), licensed under the **MIT License**.

**Used in this package:**

- Runtime rendering via the [`janczakb/blade-gravity-icons`](https://github.com/janczakb/blade-gravity-icons) Composer dependency
- Build-time icon catalog for **IconPickerField** and related tooling (`@gravity-ui/icons` npm package)
- Default and configurable icons across form components, table columns, layout primitives, and the Flex Rich Editor (via `GravityIcon` constants and `icons()` APIs)

**Source repository:** https://github.com/gravity-ui/icons
