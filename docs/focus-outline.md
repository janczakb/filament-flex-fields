# Focus outline

[← Back to Table of Contents](/docs/index)

The **Focus outline** playground hub (`/flex-fields-playground/focus-outline`) is the first item in the playground registry. It shows how keyboard focus rings render on common Flex Fields components so you can verify WCAG-visible focus in your theme.

## What it covers

- Text inputs and textareas
- SelectField triggers and menus
- Phone and credit-card composites
- Grid layouts with mixed field widths

## When to use it

- After changing global Filament or Flex Fields theme tokens
- Before shipping a customer-facing form with custom density or dark mode
- When auditing keyboard navigation alongside [Hold confirm](/docs/hold-confirm-action) and overlay pickers
